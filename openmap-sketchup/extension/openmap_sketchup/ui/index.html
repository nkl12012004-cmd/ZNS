Supabase được cấu hình trên máy chủ riêng. Dùng HTTPS khi kết nối qua mạng.

Đăng nhập Supabase

Lấy hai giá trị public trong phần API của dự án Supabase của bạn.

Chỉ dùng public key; không dùng service_role, secret key hoặc mật khẩu. Cấu hình được lưu trên máy này.

Thêm URL này trong Supabase → Authentication → URL Configuration → Redirect URLs; bật Google provider nếu dùng đăng nhập Google.
