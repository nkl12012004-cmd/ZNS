# User-supplied SVN-Avo fonts

The four TTF files were supplied by the user for this interface and are copied
byte-for-byte. Their original rights remain with their respective owners; the
SiteCraft MIT license does not grant a license to these font files.

The supplied name tables contain SVN-Avo and UTM Aptima names. The files have
OS/2 embedding flag `0x0004` (Preview & Print). This records existing metadata,
not a new font license or a claim of unrestricted public redistribution.
No font outlines, metadata, embedding flags or formats were changed.

`font-manifest.json` records the supplied names, SHA-256, size and CSS style
mapping. CSS uses the bundled files, without requesting a font service.

The user explicitly authorized publication of all four font files in GitHub ZNS
and inclusion in SiteCraft installers/source packages on 2026-11-17. Their
original rights remain unchanged; this is not an additional font license.
