# SiteCraft Flow Bridge

New, readable MIT source for SiteCraft Render AI. This extension contains no Nano Render code, activation service, API keys, local AI models or copied prompts.

1. Open `chrome://extensions` (Edge: `edge://extensions`), turn on Developer mode and choose **Load unpacked**. Select this `sitecraft_flow_bridge` folder.
2. In SketchUp open SiteCraft → Render AI → bridge settings and request a pairing code. Keep the shown port and 6-digit code.
3. Open Google Flow in Chrome/Edge, sign in yourself and open the project to use. Open this extension's popup, select the SiteCraft port and enter the code.
4. With the desired Flow tab selected, press **Kết nối tab Flow hiện tại**. Submit a render/edit/upscale job from SiteCraft. The selected tab may remain in the background.
5. For Flow controls that require a real mouse event, explicitly press **Cho phép thao tác nền** in the popup and grant Chrome's optional debugger permission. It is off until you choose it. Chrome may display a debugger banner briefly during a click. Only the paired Flow tab receives bounded mouse clicks; cookies, arbitrary JavaScript evaluation and arbitrary keyboard input are not used.

The extension operates Flow's normal interface in the chosen tab. It uploads the selected source/references, fills the prompt and submits at most once. For a stored result's edit/upscale, it can reopen that validated Flow page in this same paired tab before dispatch. The navigation intent is persisted first: a restart during navigation becomes manual rather than a second submission. Results require a new history entry in the same image-edit page, positive source association and matching prompt information; conflicting/missing metadata, an existing generation or unrelated user interaction during the wait causes a manual step. Its own narrowly identified trusted clicks are distinguished from manual input. Google does not expose a stable public DOM job-correlation API, so a concurrent session outside this page remains a limitation; use manual import whenever association is uncertain. It keeps credentials for the local worker inside the extension, never in the web page. Google credentials are not read or transferred to SiteCraft.

**2K** uses Flow's visible Download → 2K option; it never starts a replacement generation. It may be unavailable for a particular image/account. The downloaded filename/URL must identify the selected media; generic or ambiguous downloads require manual import. An output that is smaller or changes the source aspect ratio is not accepted as a successful upscale.

If Google requests sign-in, consent, CAPTCHA or quota/payment action, handle it yourself. If the page changes or a job is interrupted, SiteCraft reports that it needs your help. Download the correct result on Flow and use **Nhập ảnh** in SiteCraft, or cancel the old job and deliberately create another. A restarted extension/page never automatically submits the same job again.

Pairing is local and separate from a Google account. Ports are restricted to IPv4 localhost17865–17872. The popup lets you disconnect the chosen tab. Its optional auto-open checkbox allows reopening the previously selected project in a background tab if closed; it never resumes a possibly submitted old job. Revoke pairing in SiteCraft to invalidate the stored token. SiteCraft does not promise unlimited Google quota, fixed generation speed or pixel-identical architectural geometry. Files downloaded without a positive image association can be handled by SiteCraft's explicit Downloads-folder/manual-import workflow; this extension does not request Chrome downloads permission.

Files: `core.js` validates protocol and media; `worker.js` owns paired sessions/leases and the optional semantic click helper; `flow-dom.js` isolates observable Flow selectors; `content.js` runs one tab-bound operation; `download-observer.js` temporarily observes the image download triggered by a 2K action. Debugger permission is optional and requested only by the explicit popup button. There is no cookies permission, eval or remote code. The popup uses the same packaged SVN-Avo fonts as SiteCraft; it does not change fonts on Google's page.

Tests: from the repository root run `node tools/ai-flow-smoke.cjs`. Tests mock Chrome, DOM and network; they do not log in, upload an image to Google or execute a live AI generation.
