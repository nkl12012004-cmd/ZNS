# Readable recovered MapSKP geometry engine — editable source

The five Python source modules in this folder were reconstructed locally from
the user-supplied MapSKP package and compared against its unchanged execution.
They are ordinary editable Python: no marshal/pyc payload or bytecode loader is
included. Source hashes and original code fingerprints are in recovery-manifest.json.

The original authorship and rights of these recovered modules are retained.
The independent SiteCraft adapter/UI MIT license does not cover them. No open
source license for the original modules was found in the supplied archive;
editable source alone does not establish an open-source redistribution license.

The normal optional native import and original geometry policy checks remain.
No vendor login, signing key, native armor, vault, account or credit module is
included. No vendor grant is fabricated. The installed engine uses its original
normal optional-library branch without the absent native module.

The user explicitly approved public distribution of these recovered source files
in nkl12012004-cmd/ZNS on 2026-11-17. This approval concerns publication; the
original authorship and rights remain as stated above. An earlier automatic
review rejection concerned a protected original payload, which is not bundled.

Native .skp output requires a real Windows SketchUp API DLL. OBJ/MTL, GLB,
textures and the editable-mesh fallback have been tested locally. Actual SketchUp
SDK save/load has not been verified on this Linux machine.
