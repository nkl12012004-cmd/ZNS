# SiteCraft 0.5.0-beta.1

Adds SiteCraft Render AI alongside the existing map workspace. A new Chrome
Manifest V3 bridge drives the user's selected Google Flow image editor and
returns validated images to SketchUp. This is an independent implementation;
the supplied Nano Render installer, encrypted Ruby, scripts and identity keys
are not distributed.
Readable prompt text is reused separately with original rights, hashes and
source locations: 94 catalog records, up to 80 wired to the applicable controls.
Production Ruby-supplied base prompts remain unrecovered; preview examples are
explicitly labeled. MIT watermark helpers/masks retain upstream notices.

## Behavior

- Native viewport capture with unchanged camera/model, optional camera tracking,
  source-file/paste/drop, crop/aspect, four references and annotated region notes.
- Fresh-camera Render, custom/panoramic crop/zoom, optional viewport framing,
  reversible helper hiding, reference roles/materials, recovered preset families,
  clean comparison image, partial-ink erasing and regional edit/quick actions.
- Render/edit, reusable results/settings, before/after comparison, native save,
  persistent bounded local history and explicit manual import fallback.
- Separate Flow 2K download action; never described as local 2x/4x SR or
  guaranteed 4K/8K output. Google login, availability and quotas still apply.
- Explicit local pairing, isolated browser bearer, exact tab/session/lease,
  durable submission intent and idempotent completion. Ambiguous jobs require
  review instead of an automatic potentially billable duplicate submission.
- Background pinned-tab operation, safe exact-page reopening, optional narrowly
  scoped trusted CDP clicks and explicit auto-open opt-in. Manual handoff works
  without a bridge; a bounded Downloads watcher proposes stable image files
  for explicit confirmation. History uses lazy bounded thumbnails.
- Separate single/batch image utility: conservative known Gemini marker
  recognition/reverse alpha and explicit region fill. Originals remain intact;
  unmatched markers create no false cleaned result.
- Optional map texture enhancement runs after original-image tree analysis.
  It rejects downsampling, changed aspect, conspicuous shifts/repainting,
  transparency and EXIF rotation. Geometry and UVs remain unchanged. Original
  texture remains on failure; accepted texture/provenance reach every writer.

## Validation and limits

Local automated checks cover Python transport, media/queue persistence,
pairing/CORS, restart/cancellation, original map/export regressions, Ruby host
doubles, UI/DOM fixtures and actual Chrome-extension-to-Python HTTP transport.
Fixture results are not Google-generated images. Native SketchUp UI/SDK and
the current authenticated Google Flow UI still need an end-to-end user trial.

No quality, timing, geographic fidelity or unlimited usage claim is made.
Flow DOM changes or uncertain result association stop automation and offer
manual import. A generated perspective image is separate from actual model
geometry. The map enhancement comparison is an image heuristic, not a survey
accuracy guarantee. Existing recovered MapSKP and font rights remain unchanged.

Install the Full RBZ and load the bundled/separate Chrome bridge folder. See
[Vietnamese instructions](AI_RENDER_VI.md) and [protocol](AI_RENDER_PROTOCOL.md).
This beta does not replace the verified 0.4.2 stable release automatically.
